02 Translate a website

Open any ordinary website, click Lingua Lens in the toolbar, and choose Translate this page. Turn on Always translate this site if you want translation on future visits. Use Pause & restore original to return to the source text.

Chrome settings, the Web Store, and other protected browser pages cannot be translated.
