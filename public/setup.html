02 Translate a website

Open any ordinary website, click Lingua Lens in the toolbar, and choose Translate this page. Turn on Always translate this site if you want translation on future visits. Use Pause & restore original to return to the source text.

Chrome settings, the Web Store, and other protected browser pages cannot be translated.

Quick actions

Highlight text and right-click → Translate selection with Lingua Lens. Or use the toolbar's selected-text button.

  • Translate selection: Alt + Shift + Y
  • Translate / restore page: Alt + Shift + L

Use Alt + Shift + O to reveal the original of selected translated text. In the toolbar, expand Languages & reading to choose bilingual paragraphs.

On Mac, Alt is Option. Shortcuts may be unassigned if another app uses them.
